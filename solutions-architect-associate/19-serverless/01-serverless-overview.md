# Serverless on AWS

AWS manages the underlying servers, scaling, and infrastructure maintenance

- Usually pay per request, execution time, or consumed capacity
- Scales automatically; often able to scale to zero
- You still manage application code, data, IAM, networking, and service configuration

## Common Services

- Compute: Lambda, Fargate
- API: API Gateway
- Data: DynamoDB, S3, Aurora serverless
- Auth: Cognito
- Messaging: SQS, SNS, EventBridge
- Streaming: Kinesis Data Streams, Amazon Data Firehose
- Orchestration: Step Functions
