# AWS Lake Formation

Centralized governance and permissions for data lakes

- S3 stores lake data; Glue Data Catalog stores metadata
- Helps ingest, catalog, and secure structured / unstructured data
- Fine-grained access at database, table, column, row, and cell levels
- Integrated with Athena, Redshift Spectrum, EMR, and Glue
- Supports controlled cross-account data sharing
- Complements IAM; does not replace all IAM permissions

Exam cue: Centralized data-lake permissions, especially column-level access
