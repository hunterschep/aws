# Scalability and High Availability

- Vertical scaling: Scale up or down by changing the size of one resource
- Horizontal scaling: Scale out or in by changing the number of resources
- Vertical scaling has a hardware limit and can require downtime
- Horizontal scaling requires a distributed application

## Key Concepts

- Scalability: Ability to handle greater load by adding capacity
- Elasticity: Automatically add and remove capacity as demand changes
- High availability: Minimize downtime with redundant resources, usually across AZs
- A system can be scalable without being highly available
