# Amazon ECR

Managed registry for OCI and Docker container images

- Private repositories and ECR Public Gallery
- IAM and repository policies control push/pull access
- Native integration with ECS, EKS, and CodeBuild
- Image scanning identifies operating system and package vulnerabilities
- Tag immutability prevents an existing image tag from being overwritten
- Lifecycle policies expire old or untagged images
- Cross-Region and cross-account replication available
- Stores images only; ECS/EKS/Fargate run them
