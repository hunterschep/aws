# Storage Service Comparison

- S3: regional object storage
- S3 Glacier storage classes: low-cost object archives
- EBS: persistent block storage for EC2 in one AZ
- EBS Multi-Attach: selected `io1` or `io2` volumes, same AZ, Nitro instances
- Instance store: high-performance ephemeral block storage
- EFS: elastic shared NFS for Linux; Regional or One Zone file systems
- FSx for Windows File Server: SMB, NTFS, and Active Directory
- FSx for Lustre: high-performance parallel Linux file system
- FSx for NetApp ONTAP: NFS, SMB, iSCSI, and NetApp features
- FSx for OpenZFS: managed NFS with OpenZFS features
- Storage Gateway: ongoing hybrid access to AWS storage
- Transfer Family: managed SFTP, FTPS, FTP, and AS2 endpoints
- DataSync: managed migration and scheduled storage transfers
- Database: indexed, structured data that applications must query
