# CloudWatch Insights Features

## Container Insights

- Collect and summarize container metrics / logs
- Supports ECS, EKS, and Kubernetes on EC2; Fargate support varies by platform
- Helps inspect CPU, memory, restarts, and other workload health signals

## Lambda Insights

- Lambda extension for performance monitoring and troubleshooting
- System metrics such as CPU, memory, disk, and network usage

## Contributor Insights

- Analyze log patterns to identify top contributors, e.g., busiest source IPs
- Useful for finding heavy users, noisy hosts, or sources of errors
