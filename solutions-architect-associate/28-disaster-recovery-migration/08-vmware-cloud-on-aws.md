# VMware Cloud on AWS

Extend an on-premises VMware environment into AWS using familiar VMware tools

- VMware software-defined data center (SDDC) running on dedicated AWS bare-metal infrastructure
- Uses vSphere, vSAN, NSX, and vCenter for compute, storage, networking, and management
- Use cases: Data-center extension, migration, capacity expansion, and disaster recovery
- Workloads remain VMware VMs; different from converting them to native EC2 instances
