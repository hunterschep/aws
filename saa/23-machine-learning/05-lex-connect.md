# Amazon Lex and Amazon Connect

## Lex

- Build voice and text chatbots
- ASR recognizes speech; natural language understanding (NLU) identifies intent
- Slots collect required details, e.g., booking date
- Lambda can validate input or fulfill requests

## Connect

- Cloud contact center for customer calls and chat
- Integrates with CRM systems, Lex bots, and Lambda
- Example: Caller -> Connect -> Lex -> Lambda booking logic
