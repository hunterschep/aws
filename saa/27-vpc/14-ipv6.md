# IPv6

128-bit addresses, compared with IPv4's 32 bits (~4.3 billion addresses)

- VPC retains its primary IPv4 CIDR; add IPv6 CIDR blocks for IPv6 connectivity
- Subnets can be IPv4-only, dual-stack, or IPv6-only
- Dual-stack resources can communicate over either protocol when supported
- Amazon-provided IPv6 addresses are globally routable; routes and security rules still control access
- Private IPv6 also supported through VPC IPAM; not reachable through internet gateways
- Configure IPv6 routes and SG / NACL rules separately from IPv4
- `0.0.0.0/0`: All IPv4 destinations; `::/0`: All IPv6 destinations
