# S3 Storage Lens

Organization-wide analytics for S3 usage, activity, cost, and data protection.

- Aggregate by organization, account, Region, storage class, bucket, or prefix
- Daily dashboard with trends, outliers, and recommendations
- Export metrics to S3 or publish supported advanced metrics to CloudWatch

## Metric Categories

- Summary: total bytes and object counts
- Cost optimization: noncurrent versions and incomplete multipart uploads
- Data protection: versioning, replication, and encryption coverage
- Access management: Object Ownership and public-access posture
- Performance: request and transfer patterns
- Activity and status codes: request counts and response details

## Free vs. Advanced

- Free tier: default account dashboard and core metrics
- Advanced tier: paid metrics, prefix aggregation, activity, status codes, and recommendations
