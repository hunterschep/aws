# EC2 IP Addresses

- Private IP: Reachable within private networks; not directly routable from the internet
- Public IPv4: Internet-routable and mapped to the instance's private IP
- Auto-assigned public IPv4 changes after stop/start
- All public IPv4 addresses incur hourly charges

## Elastic IP

- Static public IPv4 allocated to your account in one Region
- Remains allocated until released and can be remapped for failover
- Continues to incur charges while allocated

Avoid depending on fixed public IPs when possible. Prefer a load balancer with a Route 53 alias record.
