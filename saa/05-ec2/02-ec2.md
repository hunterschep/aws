# Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable virtual machines as Infrastructure as a Service (IaaS).

## Building Blocks

- EC2 instances: Virtual machines
- Amazon EBS: Network-attached block storage
- Amazon EFS: Shared network file storage
- Elastic Load Balancing (ELB): Distributes traffic
- Auto Scaling groups (ASGs): Adjust and maintain instance capacity

## Configuration Choices

- Operating system: Linux, Windows, or macOS
- Compute: vCPUs and RAM
- Storage:
  - Network: EBS or EFS
  - Local hardware: EC2 instance store
- Networking: Bandwidth, IP addresses, and network interfaces
- Firewall: Security groups
- Bootstrap script: EC2 user data
  - Runs as root at first boot by default on Linux
  - Use for installation and initial configuration

## IP Address Behavior

- Primary private IPv4: Stays with the instance through stop/start
- Auto-assigned public IPv4: Changes after stop/start
- Elastic IP: Static public IPv4 until released

## Instance Types

Example: `m5.2xlarge`

- `m`: Instance family
- `5`: Generation
- `2xlarge`: Size within the family

### Main Families

- General purpose: Balanced compute, memory, and networking; web and application servers
- Compute optimized: CPU-intensive batch jobs, transcoding, HPC, and modeling
- Memory optimized: In-memory databases, caches, and real-time processing
- Storage optimized: High local IOPS or throughput; NoSQL, OLTP, and data warehousing
- Accelerated computing: GPUs or custom accelerators for ML, graphics, and specialized compute

Burstable `T` instances earn and spend CPU credits.
