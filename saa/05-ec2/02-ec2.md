## Instance Types 

Naming convention m5.2xlarge 

- m = instance class 
- 5 = generation (5th)
- 2xlarge = size within instance class 

1. General purpose: Balanced -> web servers or code repositories 

2. Compute optimized: Optimized for CPU intensive tasks -> batch processing, transcoding, HPC, modeling

3. Memory optimized: Optimized for memory intensive tasks -> in memory DBs, web scale cache stores, real time processing 

4. Storage optimized: Optimized for storage intensive tasks requiring high read and write -> OLTP systems, relational / noSQL, data warehousing, Redis
