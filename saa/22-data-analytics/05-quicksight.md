# Amazon QuickSight (Amazon Quick)

Serverless BI and interactive dashboards

- Use cases: Reports, visualizations, ad hoc analysis, embedded dashboards
- SPICE: In-memory engine for imported data; refresh to pick up source changes
- Direct query: Query supported sources without importing into SPICE
- Sources: Athena, Redshift, RDS / Aurora, S3, OpenSearch, supported SaaS / databases
- File imports: CSV, Excel, JSON
- QuickSight users / groups control sharing; IAM or federated identities can sign in
- Enterprise row-level security: Restrict which rows each reader can see
