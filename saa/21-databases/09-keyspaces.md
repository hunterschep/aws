# Amazon Keyspaces

Fully managed, serverless Apache Cassandra-compatible database

- Wide-column data model and Cassandra Query Language (CQL)
- Works with many existing Cassandra drivers and tools
- No clusters, nodes, patching, or server management
- On-demand or provisioned capacity modes
- Data replicated across three Availability Zones by default
- Multi-Region replication supports active-active reads and writes
- TTL, encryption, and point-in-time recovery
- Cassandra compatibility is not complete; verify supported CQL features

Best for Cassandra migrations and high-throughput workloads already modeled for CQL
