# Amazon Timestream

AWS services for time-series metrics, events, and telemetry

## Timestream for LiveAnalytics

- Fully managed, serverless time-series database with SQL queries
- Recent data in a fast memory store; older data in a magnetic store
- Retention policies automatically tier and expire data
- Scheduled queries create rollups and precomputed aggregates
- Use cases: IoT telemetry, application metrics, and real-time analytics
- Closed to new customers after June 20, 2025; existing customers can continue

## Timestream for InfluxDB

- Managed InfluxDB-compatible time-series database
- Instance/cluster based rather than serverless
- Fits migrations using InfluxDB APIs, tools, and query languages
