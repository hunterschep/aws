# Amazon S3

Massively scalable object storage, not a relational database or file system

- Stores objects in buckets using unique keys and metadata
- Strong read-after-write consistency for object PUT, DELETE, GET, and LIST
- General purpose buckets store data redundantly across multiple Availability Zones
- Storage classes optimize frequent, infrequent, archive, or unknown access patterns
- Lifecycle rules transition or expire objects automatically
- Versioning protects against accidental overwrite/deletion
- Same-Region or Cross-Region Replication copies objects asynchronously
- Event notifications integrate with SNS, SQS, EventBridge, and Lambda
- IAM, bucket policies, encryption, and Block Public Access secure data

Use cases: data lakes, backups, archives, media, logs, and static assets

- Athena queries structured data in S3 without loading it into a database
