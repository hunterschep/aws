# Amazon DynamoDB

AWS-native, serverless key-value and document database

- Multi-AZ, single-digit millisecond performance at scale
- Primary key: partition key, or partition key + sort key
- Maximum item size: 400 KB
- Access patterns and partition-key distribution drive the data model
- On-demand capacity for variable traffic
- Provisioned RCU/WCU with Auto Scaling for predictable traffic
- Global tables for active-active multi-Region access
- DAX for microsecond cached reads; Streams for change events
- TTL, transactions, backups, and point-in-time recovery

Choose DynamoDB for known key-based access patterns, not joins or ad-hoc SQL
