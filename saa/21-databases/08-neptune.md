# Amazon Neptune

Fully managed graph database for highly connected data

- Property graphs: Gremlin and openCypher
- RDF graphs: SPARQL
- Optimized for relationship traversals that require complex SQL joins otherwise
- Use cases: fraud detection, recommendations, knowledge graphs, and social networks
- One primary writer and up to 15 read replicas
- Multi-AZ cluster storage, automatic backups, point-in-time recovery, and failover
- Neptune serverless scales database compute capacity automatically
- Neptune Streams exposes ordered change records for downstream processing

Choose Neptune when relationships and graph traversals are the core access pattern
