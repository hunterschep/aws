# Amazon Quick / Other Tools

- Amazon Quick: business intelligence with generative AI features; analyze organizational data / build dashboards and answer business questions
- Kiro: AI-assisted software development environment
- Strands Agents: open-source SDK / framework for building agents
- Bedrock AgentCore: services to build, deploy, operate, and govern agents
- MCP: connection protocol for exposing tools / context to compatible agents; permissions still come from the connected system / app

Exam cue: distinguish model service (Bedrock), custom ML platform (SageMaker AI), agent framework (Strands), managed agent infrastructure (AgentCore), and BI (Quick).
