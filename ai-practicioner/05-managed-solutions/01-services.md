# Managed AI Services

- Amazon Comprehend: NLP on text; sentiment, entities, key phrases, language, PII
- Amazon Lex: conversational bots / virtual agents
- Amazon Polly: text to speech
- Amazon Transcribe: speech to text
- Amazon Translate: machine translation
- Amazon Rekognition: image / video analysis (objects, faces, text, scenes)
- Amazon Textract: OCR plus structured data extraction from forms / tables
- Amazon Personalize: individualized recommendations
- Amazon SageMaker AI: custom ML lifecycle; SageMaker JumpStart: discover / start from models and solution templates
- Amazon Bedrock: managed FMs, customization, RAG, agents, Guardrails, evaluation
- Amazon Nova: AWS model family (text / multimodal understanding, image / video generation, speech)

Quick matching: scanned invoices / forms -> Textract; image moderation / object labels -> Rekognition; call transcription -> Transcribe; sentiment / entities -> Comprehend; recommendations -> Personalize.
