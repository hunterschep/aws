# Amazon Nova

Amazon's FM family available through Bedrock. Choose model by modality, quality, latency, cost, and task; confirm current IDs / availability in the model catalog.

- Nova Micro: text-only, lowest latency / cost for simple text tasks
- Nova Lite: fast, low-cost multimodal understanding (text, image, video)
- Nova Pro: higher capability multimodal understanding (text, image, video); stronger quality / complexity needs
- Nova Premier: highest capability in the understanding family; can act as a teacher for distillation to Micro / Lite / Pro
- Nova Canvas: generate / edit images
- Nova Reel: generate video
- Nova Sonic: speech-in / speech-out real-time conversational applications

Exam cues:

- Simple text classification / extraction at low cost -> Micro
- Cost-efficient image / video / text understanding -> Lite
- Higher quality / complex multimodal task -> Pro
- Teacher model for distillation -> Premier
- Image generation -> Canvas; video generation -> Reel; speech conversation -> Sonic

Model capabilities, context limits, Regions, and supported modalities vary; don't assume every Nova model handles every input or output type.
